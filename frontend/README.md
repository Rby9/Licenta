# Frontend HoteluriRo

Interfață React + Vite. Documentația principală este în [README-ul proiectului](../README.md).

Din acest director:

```sh
npm run dev
```

Backendul trebuie să ruleze separat pe portul 5001. Deschide http://localhost:5173.

- `npm run build` compilează în `dist/`.
- `npm run lint` verifică problemele de cod.
- `src/pages/` conține paginile; `src/components/` conține elementele reutilizabile.
- `vite.config.js` trimite `/api` și `/uploads` către backendul local.
