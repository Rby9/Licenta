# Fonturi PDF

`Roboto-Regular.ttf` și `Roboto-Bold.ttf` provin din [repository-ul Google Fonts Roboto](https://github.com/googlefonts/roboto-2/tree/main/src/hinted). Licența Apache 2.0 originală este păstrată în `LICENSE-Roboto.txt`.

Fișierele sunt incluse local pentru generarea PDF fără dependențe de fonturile sistemului de operare. Ambele conțin diacriticele românești.
